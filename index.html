VSは、OBSの中で決める。

17LIVE公式OBSプラグインのログインをそのまま共有。友だちを1対1のVSへ誘って、 配信中そのものの映像・音声をOBSから相手に送信。リスナーに見えている画面も確認できます。

対応: 1対1のフレンドVSのみ（4人VSは未対応。1対1のフレンドVSはプラグインから直接「誘って」開始できます（v0.1.4〜））

ダウンロード インストール方法 仕組みを知る

?何ができるプラグイン？

既存の17LIVE配信環境（サーバー送出）に追加で入れる、VS支援だけの特化プラグインです。

🔑

ログイン共有

公式17LIVEプラグインで一度ログインしていればOK。このプラグインで再ログインは不要です。

🎯

1対1フレンドVS専用

友だちを1対1でVSに誘う使い方に対応。4人VSは未対応です。

📤

誘う主導線

Dockで17LIVEにログインし、友だちのuserIDを入力して「招待してPUSH」。相手が受容すると、OBSの映像・音声がそのまま自動でVSに流れ始めます。

📺

リスナー视角プレビュー

視聴者に見えているVS合成画面をそのまま確認。画面が逆でも即気づけます。

🎧

相手の音声（任意）

イヤホンでのみ聞けるMonitor-Onlyルート。配信音には絶対に乗りません。

📡

VSへ映像/音声PUSH

Dockのワンクリックで仮想カメラ開始。配信中そのものの映像・音声をVS相手に無劣化で送信します。

🪟

シーン切り替え不要

VS中の画面演出は既存のOBS/サーバー合成が担当。プラグインは操作と確認だけ。

2友だちを誘ってVS開始（ダイレクトPUSH・推奨）

1対1のフレンドVSを、OBSから直接始めます。相手は17LIVEアプリ/配信画面で招待を受容するだけでOK。4人VSは未対応です（1対1のみ）。映像・音声の送出は仮想カメラ経由です（仮想カメラ不要の直接PUSHは近日対応予定）。

準備（初回1回だけ・Windows）

  1. OBSの「ツール」→「仮想カメラ」が開けることを確認します（PUSHの送信元として使われます。設定は不要で、開ければOKです）。
  2. 17LIVE側のカメラ選択で「OBS Virtual Camera」を選ぶ準備をします（実際に選ぶのは招待を受けたときです）。

VSを始める

  1. OBSの「17LIVE VS」Dockで 17LIVE IDとパスワード を入力し「VSログイン」を押します（入力はこのPC内で完結し、配信基盤への認証にのみ使われます）。
  2. 誘う友だちの userID を入力し「招待してPUSH」を押します。相手の配信中である必要はありません（友だち同士の1対1VSとして開始されます）。
  3. 相手に招待が届くので、相手が17LIVE側で受容します。
  4. 受容されると「VS接続OK」が表示されます。そのまま仮想カメラPUSHが始動します（下の3章どおりに「仮想カメラを開始」→17LIVE側で「OBS Virtual Camera」選択）。Dockプレビューに映っているものがそのまま相手に見えます。
  5. 終了は「VS停止」を押します（黒い窓は次回そのまま使えます）。
📝 相手の見つけ方相手のプロフィールURL末尾の英数字列がuserIDです。招待が通らない場合は、相手と相互フォロー関係にあるか確認してください（フレンドVSは友だち限定です）。
⚠ 4人VSについて4人VS（マルチPK）はこのプラグインでは開始できません。4人VSには対応予定がありません。1対1のフレンドVS専用としてお使いください。

3（代替）仮想カメラ経由でVSへPUSH

VSの相手へ今OBSで配信している映像と音そのものを送ります。カメラで撮り直すのとは違い、配信用の映像を無劣化でそのまま複製する仕組みなので、相手が見る映像＝リスナーが見ている映像が保証されます。

  1. Dockの「仮想カメラを開始」を押します（またはOBS「コントロール」→「仮想カメラを開始」）。ボタンが緑になればPUSH中です。
    ※「仮想カメラ」はWebカメラのことでなく、OBSの配信画面そのものを出力するOBS標準機能です。
  2. 17LIVEのVS画面にあるカメラ選択で「OBS Virtual Camera」を選ぶと、OBS画面がそのまま送られます ✓
  3. 音声も送る場合（任意）: 無料の仮想オーディオアプリ（Windows: VB-CABLE / macOS: BlackHole）を1回だけ導入すると、OBSの音（声・BGM・ゲーム音のミックス済み）をVS側のマイクとして相手に送れます。手順: OBS「音声の高度な設定」→ 音声モニタ先を仮想ケーブルに → VS側のマイク選択をそのケーブル（CABLE Output / BlackHole）に。
🍎 macOSで「仮想カメラシステムプロセスが見つかりませんでした」と出たら（初回1回だけ） OBSをドラッグでインストールした場合、macOS側のカメラドライバ登録が抜けることがあります。ターミナルで次の2行を実行（管理者パスワードを聞かれます）し、ログアウト→ログイン（または再起動）してください: 
sudo mkdir -p /Library/CoreMediaIO/Plug-Ins/DAL
sudo cp -R /Applications/OBS.app/Contents/PlugIns/mac-virtualcam.plugin /Library/CoreMediaIO/Plug-Ins/DAL/
🎧 ハウリング注意相手の声はイヤホンでのみ聞いてください。スピーカーで再生すると声がマイク経由で相手にループします。

4プレビュー＆音声レベル

Dock内に「相手に送られている映像そのもの」をリアルタイム表示します。画面落ち・构图崩れの即検知用です。

  1. Dockの「映像供給」がオンのとき、プレビューにOBS出力（1280×720）が約10fpsで映ります。
  2. 下部の左右バーは送出音声のレベル（ピープメーター）です。声・BGMが上がれば振れ、無音なら沈みます。
  3. プレビューをダブルクリックで全画面表示（もう一度ダブルクリックで戻ります）。配信中もOBS本体の操作はそのままできます。
  4. プレビュー・メーターともにOBS本体の配信には干渉しません（受け取り専用です）。

5相手の音声を聞く（イヤホン必須）

🎧 配信中にスピーカーで聞かないで！相手の音声をスピーカーで流すと配信にエコー（ハウリング）として乗ってしまいます。

プラグインの音声ルートは「Monitor Only（モニターのみ）」設計です。これは：

✅イヤホン（モニター）には相手の声が聞こえる
❌配信中の視聴者にはあなたのスピーカー音が返らない（配信に混ざらない）

つまり「イヤホンをしていればOK、スピーカーだとハウリング」という単純なルールです。Dock下部の「相手の音声を聞く」は既定OFFです。

6よくある質問・トラブル

症状対処
「セッション: 未取得」と出る公式17LIVEプラグインでログインしてください。OBSを一度終了→再起動すると認識します。
「仮想カメラシステムプロセスが見つかりませんでした」（macOS）上記PUSH節のターミナル2行を実行し、ログアウト→ログイン（または再起動）してください。OBSのドラッグインストールでたまに起きます。
相手に映像が伝わらないVS/PK側のカメラ選択がWebcamのままです。「OBS Virtual Camera」を選び、Dock（またはコントロール）で仮想カメラを開始してください。
Dockが見当たらないOBSメニュー「表示」→「ドック」→「17LIVE VS」にチェックを付けてください（v0.1.1〜）。
Dockが消えて戻らないOBSを終了し、設定ファイルの DockState= 行を削除してから起動すると復帰します（Windows: %APPDATA%\obs-studio\user.ini、macOS: ~/Library/Application Support/obs-studio/user.ini、Linux: ~/.config/obs-studio/user.ini）。
VSに誘いたいDockの「VSログイン」→相手userID→「招待してPUSH」でOBSから誘えます（2章）。17LIVEアプリ側から誘う既存運用もそのまま使えます。4人VSには未対応です。
「招待してPUSH」が失敗する①黒い窓（livit17-pushd）が起動しているか②VSログインし直しか③相手と相互フォローかを確認してください。相手が招待を受容しないと30秒ほどでタイムアウトになります。
ハウリングするイヤホン利用に切り替えてください。音声切替は既定OFFです。
OBS起動時にエラーOBSのバージョンを32以上へ更新してください（v0.1.3はOBS 32対応）。公式プラグイン版との競合は今のところ確認されていません（同居動作確認済）。
